# kricliff.github.io

Website for apps by Kristian Clifford, served with GitHub Pages.

- `koi-garden/` – Koi Garden: Block Puzzle (about, support and privacy policy)
- `koi-garden/play/` – a test version of the game to play in the browser, copied from `www/` in the mentalblock repo with `bash store/tools/publish-play.sh`. Hidden from search engines. Do not edit it here.
- `app-ads.txt` – authorised ad sellers for AdMob (replace the publisher ID)

The source of these pages also lives in the `site/` folder of the mentalblock repo.
